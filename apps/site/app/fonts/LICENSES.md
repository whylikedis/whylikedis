# Font licences

The three typefaces in this folder are third-party material, not part of this repository's own
licence. Each stays under the SIL Open Font License, Version 1.1; the licence text, with its
copyright line, is next to the files.

| Family            | Files                       | Licence text                                           |
| :---------------- | :-------------------------- | :----------------------------------------------------- |
| Heebo             | `heebo-*.woff2`             | [OFL-Heebo.txt](OFL-Heebo.txt)                         |
| Newsreader        | `newsreader-*.woff2`        | [OFL-Newsreader.txt](OFL-Newsreader.txt)               |
| Noto Naskh Arabic | `noto-naskh-arabic-*.woff2` | [OFL-Noto-Naskh-Arabic.txt](OFL-Noto-Naskh-Arabic.txt) |

The files are the woff2 builds Google Fonts served for the committed screenshot baselines, kept
byte for byte (the file name carries the first ten hex digits of its SHA-1). Do not re-download them:
Google served two different builds of Newsreader to two builds of one commit.
